# Анализ нагрузки колл-центра

## О проекте
Анализ 50 000 звонков колл-центра. Цель: выявить неравномерность нагрузки на операторов и предложить рекомендации по её распределению.

## Данные
- Источник: Kaggle (ConnectTel Kenya Call Center — 50K Calls).
- Объем: 50 000 звонков, 22 колонки.

## Инструменты
- Python (Pandas)
## Ключевые выводы
1. **Средняя нагрузка:** 111.11 звонков на оператора.
2. **Самый перегруженный:** AG250 — 149 звонков (+38 к среднему).
3. **Самый недогруженный:** AG241 — 74 звонка (-37 к среднему).
4. **Разница:** нагрузка между операторами отличается в 2 раза.

## Рекомендация
Для сотрудников с положительным отклонением уменьшить входящий поток звонков, перенаправив его на менее загруженных операторов.
Для сотрудников с отрицательным отклонением увеличить нагрузку, добавив им звонков.
Цель — привести фактическое количество звонков каждого оператора к среднему значению (111.11), чтобы нагрузка была равномерной.
